
# PDBC Student Management System

## Project Overview
A Student Management System developed using Python and MySQL Database Connectivity (PDBC).

The application allows users to manage student records through a graphical interface and perform database operations.

## Technologies Used
- Python
- MySQL
- MySQL Connector
- Tkinter
- MySQL Workbench

## Features
- Add Student Records
- View Student Records
- Search Student Records (CLI version)
- Update Student Details
- Delete Student Records
- Python-MySQL Database Connectivity
- GUI using Tkinter

## Database Structure
Database: student_db

Table: students

Columns:
- student_id
- name
- age
- course
- email

## Installation

1. Clone the repository.
2. Install dependencies:

   pip install -r requirements.txt

3. Create the database by executing database.sql in MySQL Workbench.
4. Set your MYSQL_PASSWORD environment variable.
5. Run the application:

   python gui_app.py
